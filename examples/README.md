# Learn by Example

This folder contains runnable, bite-sized C programs. Each file is heavily commented like explaining to a 5-year-old, in three languages:
- English (EN)
- Sinhala (SI)
- Tamil (TA)

## How to use
- Build all examples:
  - make examples
- List the example names:
  - make list-examples
- Run one, e.g. `hello_world`:
  - make run-hello_world
