# 3. C Fundamentals

## Variables and scope
- Declaration: `int x;`
- Initialization: `int y = 10;`
- Scope: block (local), file (static), global

## Constants
- Literals: `42`, `3.14`, `'a'`, `"hello"`
- `#define PI 3.14159`
- `const int DAYS = 7;`

## Data types
- Primary: `char`, `int`, `float`, `double`, `void`
- Qualifiers: `short`, `long`, `signed`, `unsigned`
- Derived: arrays, pointers, functions
- User-defined: `struct`, `union`, `enum`

See examples in `src/02_basics/`.
