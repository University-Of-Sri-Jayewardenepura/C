# 4. Operators in C

Arithmetic, relational, logical, bitwise, assignment, and `sizeof`.

## Examples

### Minimum of Two (`min_of_two.c`)

Demonstrates the ternary conditional operator (`?:`):

```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Enter two integers (a b): ");
    scanf("%d %d", &a, &b);
    int min = (a < b) ? a : b;
    printf("Min = %d\n", min);
    return 0;
}
```

### Prime Check (`is_prime.c`)

Uses arithmetic (`%`), relational (`<=`, `==`), and logical operators in a loop:

```c
#include <stdio.h>

int is_prime(int n) {
    if (n <= 1) return 0;
    for (int i = 2; i * i <= n; i++) if (n % i == 0) return 0;
    return 1;
}

int main(void) {
    int n; printf("Enter n: "); scanf("%d", &n);
    printf(is_prime(n) ? "Prime\n" : "Not prime\n");
    return 0;
}
```
